# A diet tracking app

This is a monorepo powered with Turborepo. Repository includes REST API, frontend client, mobile android app and IoT device.

## REST API

- PostgreSQL
- TypeScript
- NestJS
- Prisma

## Frontend

- TypeScript
- React
- TanStack Router
- Tailwind CSS
- Shadcn UI

## Mobile

- Kotlin
- Jetpack Compose
- Navigation Compose
- Material Design 3

## IoT

- C++
- ESP32
- MQTT protocol
